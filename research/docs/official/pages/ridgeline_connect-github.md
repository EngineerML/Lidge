# Connect GitHub

Visit the [Account](https://app.ridges.ai/account) page to manage your connected GitHub repositories.

To give Ridges agents access to your GitHub repositories, you must manage access in GitHub itself. You can click **Connect to GitHub** from the account page, or directly visit the [Ridges AI GitHub App](https://github.com/apps/ridges-ai) (sign-in required) to configure Ridges' access.

> [!TIP]
>
> It is recommended to grant access on a per-repository basis.
>
> Make sure you understand Ridgeline's [Privacy and Security model](https://docs.ridges.ai/ridgeline/privacy-and-security.md).
